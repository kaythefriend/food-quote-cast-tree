# Food Quote Cast Tree

A public, responsive visualization of the recursive Farcaster conversation growing from a root cast. Built as a standalone Next.js app and kept separate from the POIDH project.

## Environment

Set `NEYNAR_API_KEY` in Vercel. The server route uses Neynar only on the server, so the key is never exposed to browsers.

Root cast: `0x3db990553cbe9e8e8993504624b5c2aaf483aa73`
